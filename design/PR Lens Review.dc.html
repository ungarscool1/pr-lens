Description · maria-k

Users get logged out after every deploy because the session store is cold for the first few seconds (#790). This adds an in-process memo so a refresh that misses the store can still succeed, and stops treating a missing session as an error.

Testing: deployed to staging twice with no logouts. Unit tests pass locally.

Linked issue #790 · closes

Users logged out after deploy. After each deploy roughly 4% of active users are signed out. Store warm-up takes 3–8 s and refreshes in that window fail with AuthError.
PR Lens summary · private

Adds a process-local memo as a fallback when the session store misses, and makes refreshSession return null instead of throwing on an expired token. The return-type change is the part most likely to break callers.
